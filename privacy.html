DANNY KIND LEGAL ATLAS

Privacy

DKLA is a personal project. It uses its own analytics system to understand use of the atlas, maintain it, and investigate security problems. Collection starts automatically; this page is an informational notice.

What is recorded

For full collection, a first-party visitor identifier connects visits from the same browser. A server-set cookie and copies in localStorage, IndexedDB and an origin-local cache help recover that identifier if one copy is missing. Clearing all site data removes these copies. A verified ratings sync code can link devices to a shared profile; the analytics database stores a hash of that code.

Session records include IP address, network name and ASN, approximate country, region, city and postal area when available, browser and operating-system versions, language, time zone, screen and viewport size, pixel ratio, pointer and touch support, appearance preferences, and browser-exposed connection, memory and core information. Entry routes, referrer URLs and campaign parameters may also be recorded.

Activity records cover entries and reading sections, active time and reading-panel scroll depth, searches and their results, map navigation, dictionary, sources and PDF pages, timelines, Supreme Court history, Cold Call, authority maps, study features, recall ratings, sync success, exports, printing, installation, offline use and technical errors. Copy events record the entry, section and character count. Notes, raw sync codes, copied text and other typed input are excluded from analytics. Text you submit in the request form below is stored as your request.

Profiles and regional collection

The owner can give profiles private labels, watch for returns, and review possible links suggested by passive network, device and study-pattern similarities. Similarity is a heuristic, not proof of a person’s identity. Manual links can be reversed. California receives full collection, while possible-same-person scoring is disabled for profiles with a California visit. Verified sync-code linking remains available there. No canvas, audio, font or WebGL probing is used.

In the EEA and United Kingdom, the reduced tier records anonymous visit counts, the atlas build, country and entries opened. It creates no persistent visitor identifier or profile. Other regional restrictions can reduce or disable collection. Missing location headers default to full collection.

Storage and access

Records are stored in the owner’s Neon database, with access through a password-protected admin dashboard. They are not sold or used for advertising. Full detail has no fixed deletion date. If capacity runs short, the owner can expand storage or pack the oldest details into retained session summaries. Optional return emails contain a profile label and dashboard link. Infrastructure providers process requests to host the site and database; the browser sends analytics only to DKLA’s own origin.
