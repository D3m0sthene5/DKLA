DANNY KIND LEGAL ATLAS

Privacy

DKLA is a personal project. It uses its own analytics system to understand use of the atlas, maintain it, and investigate security problems. Collection starts automatically; this page is an informational notice.

What is recorded

For full collection, a signed first-party browser cookie connects return visits from the same browser. The cookie is Secure, HttpOnly and SameSite=Lax, with a rolling 366-day lifetime. DKLA no longer reads or writes identity recovery copies in localStorage, IndexedDB or an origin-local cache. Older copies may remain until you clear site data, but cannot restore recognition. Deleting the cookie, using another browser or private browsing can create a new profile. A browser profile does not identify a person by name.

Session records include IP address, network name and ASN, approximate country, region, city, postal area and rounded IP-derived map coordinates when available, browser and operating-system versions, language, time zone, screen and viewport size, pixel ratio, pointer and touch support, appearance preferences, and browser-exposed connection, memory and core information. Entry routes, referrer URLs and campaign parameters may also be recorded.

Activity records cover entries and reading sections, active time and reading-panel scroll depth, searches and their results, map navigation, dictionary, sources and PDF pages, timelines, Supreme Court history, Cold Call, authority maps, study features, recall ratings, sync success, exports, printing, installation, offline use and technical errors. Copy events record the entry, section and character count. Notes, raw sync codes, copied text and other typed input are excluded from analytics. Text you submit in the request form below is stored as your request.

Profiles and regional collection

The owner can give browser profiles private labels and watch for returns. DKLA no longer scores browser, network or study-pattern similarities to suggest the same person, and ratings sync codes no longer link analytics profiles. Historical records and previously combined profiles are retained and labelled as historical; this change does not erase or split past records. No canvas, audio, font or WebGL probing is used.

In the EEA and United Kingdom, the reduced tier records anonymous visit counts, the atlas build, country and entries opened. It creates no persistent visitor identifier or profile. Other regional restrictions can reduce or disable collection. Missing location headers default to full collection.

Storage and access

Pending analytics activity stays only in the open page’s memory. It may be sent when the connection returns, but is not recovered after the page closes. Saved study work and ratings use their existing separate storage and sync.

Records are stored in the owner’s Neon database, with access through a password-protected admin dashboard. They are not sold or used for advertising. Full detail has no fixed deletion date. If capacity runs short, the owner can expand storage or pack the oldest details into retained session summaries. Optional return emails contain a profile label and dashboard link. Infrastructure providers process requests to host the site and database; the browser sends analytics only to DKLA’s own origin.
