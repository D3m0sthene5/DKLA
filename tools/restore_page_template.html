Restore the scanned pages

The atlas shows each casebook and packet page as a scanned image kept in the DKLA-sources/ folder beside DKLA-r8.html. Those 1,643 images and PDFs (about 250 MB) were never in the download; they live inside your original self-contained file DKLA-r8-rebuilt.html (363 MB). This page copies them out of that file into the folder. Nothing is uploaded anywhere; everything happens in your browser.

Step 1 · The original file

Pick DKLA-r8-rebuilt.html (or any complete DKLA file that still has the pages inside it, such as DKLA-standalone.html).

Step 2 · The atlas folder

Pick the folder that holds DKLA-r8.html. The pages are written into DKLA-sources/ inside it. Chrome and Edge ask you to allow the page to save files there.

This browser cannot write into folders. The pages will be offered as a ZIP file instead: unzip it beside DKLA-r8.html so that the folder DKLA-sources/ sits next to it.

Step 3 · Restore

Every file is checked against its stored checksum before it is written. Files already present and matching are skipped, so the page can be run again safely.

What this does, in plain words

The manifest embedded in this page lists every image and PDF, where it sits inside the original file's data blocks, and its SHA-256 checksum. The page reads the original file, finds each block, decodes the file, verifies the checksum and saves it under the path the atlas expects. It only reads the original; it never changes it. Run it once; afterwards open DKLA-r8.html and the pages appear.
